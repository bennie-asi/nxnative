# Resident Evil Revelations: experimental bring-up

Title ID `0100643002136000`, update `v65536` (display version 1.0.1), SDK 1.6.0, MT Framework, NVN. This title has not been verified playable on macOS or iOS. Keep its provisional profile and all extracted files in the game's work directory until runtime behavior is measured.

The combined XCI contains both an Application CNMT and a Patch CNMT. Their Program NCAs share a header title ID, so selecting by header or file order can silently take the base. `nx_extract --inspect` catalogs the CNMT records; extraction pairs Program and Control by the selected record's content IDs. The base `main` build ID is `7b0e2611e8c9cae5a26e427362c72a8f`; update 1.0.1 is `99e56e5136a1316b0fe9e3fb6dd2dd2f`.

ARC version 9 has 64-byte paths and 84-byte entry records. The stored size, full raw size, separate flags and 32-bit offset are at entry offsets `0x44..0x53`. In particular, the shader member in `nativeNXx64/sa/NX_64/root.arc` expands to 651,519,592 bytes; ARC 7's 29-bit raw-size mask truncates it. Its SPK puts a `0x838`-byte control section before code, with metadata between records. Both ARC 7 and the newer code-before-control SPK layout remain supported.

The updated game's seven modules rewrite successfully. Two older compiler forms needed generic handling: `main+0x8bb5fc` bounds an offset-table index with `tbnz` and a low-bit `and`; `main+0x982008` schedules the table load 19 instructions before its branch. Inference checks register writes and table bounds rather than applying a title-specific address patch.

The extracted package contains 121,428 unique shaders (60,714 vertex, 60,714 pixel). All converted to SPIR-V with the checked-in translator, with zero failures. Metal compilation, native boot, rendered frames, memory use, input and audio still require measurement. A generated IPA is not evidence of playability; final iPhone validation must include the app's `Documents/log.txt`.

For a faster SDK initialization loop, **Probe native SDK startup** accepts an encrypted prepared-module bundle through the `CI_PROBE_JSON` secret (`url` and required `sha256`), encrypted with `IPA_PASSWORD`. The archive layout is `<title>_build/profile/<title>/` plus `<title>_build/patched_<version>/`. Supply the title ID and version as workflow inputs. Its encrypted diagnostic artifact records the startup log and summary. This probe can omit RomFS; asset failures after initialization are then expected, and cannot establish game or rendering compatibility. Full-file extraction and the normal IPA workflow remain required.

Native startup reached `nnMain`, then dereferenced a null IRS service at `main+0xacd240`. The host now registers `irs`, reports disconnected cameras and supports the service's coherent shared-memory mappings. Startup then reached `audren:u`, which this SDK calls because it contains no `ExecuteAudioRendererRendering` / DFC CPU renderer. Its `AudioRendererParameter` is `0x34` bytes, with the revision at `+0x30` (`sdk+0x1593b4` initializes it); the newer CPU/manual rewrite corrupts that revision. A capability check now preserves the old parameter. SDK 1.6 uses REV2, not REV1.

The captured first update contains 182 voice/channel slots, 26 effect slots, two mixes (6 and 14 buffers) and one device sink, at 48 kHz with 240 samples per frame. `hle_audren_dsp.c` processes the old protocol: PCM and DSP ADPCM decoding, resampling, voice filters, submix routing, BufferMixer, Aux rings and an I3DL2-compatible reverb. The reverb is an approximate delay network, not an impulse-exact reproduction of Nintendo's DSP. Splitters, other effects, circular sinks and differing submix rates are rejected. The generic frontend serializes updates with rendering, paces four PCM buffers through the host output, signals frame events and joins the thread on Stop/Close. All 196 synthetic DSP checks and 85 service/shared-memory checks passed on the Mac runner. The real game opens the renderer, submits updates and starts PCM output before reaching graphics initialization. Actual game audio still needs device validation.

The standard GitHub `macos-26` runner reports `Apple Paravirtual device`, no Apple7/Apple9 family, no residency sets, and `Device does not support Metal 4.` for its command queue. The native probe aborts at `mtl_init` for this infrastructure limitation, before asset loading or drawing. `ci_metal_capabilities.m` records these capabilities independently of the offline Metal compiler. Offline iOS compilation can still proceed; use the full workflow without `native_probe` on this runner, and do not describe that build as runtime validation. Target device: iPhone 15 Pro. The iOS host now uses an A14/M1 CPU baseline rather than A18/M4, retaining LSE atomics and the project's advertised M1/A17 Pro support.

For optional protocol diagnostics, `DM_AUDREN_LEGACY_CAPTURE` (or `ci_native_probe.py --capture-audio`) saves the first request and stops with exit 43 before playback. Normal probes no longer force this mode. Keep these diagnostics encrypted: they contain pointers and may contain audio metadata from the game.

Static NVN analysis finds two references to the unimplemented `nvnCommandBufferDrawTexture` pointer (`main+0xabae34`, `main+0xabb2f0`). The host previously advertised `SUPPORTS_DRAW_TEXTURE` (`0x47`) as true; it now reports false for this optional feature. This corrects the advertised capability, but does not establish that this engine has or selects a fallback. Watch the first device log for calls to the stub. The loader also asks for `nvnDeviceWaitForError`; no static references outside its loader were found. These are static observations, not evidence of a rendered frame.

The first full CI attempt exceeded its 350-minute job timeout during Metal compilation, at about 75,298 / 121,428 shader keys. It produced no IPA. A later attempt could not download the source because the temporary HTTPS bridge had already closed. The sharded workflow stages this title once, compiles eight subsets with the unmodified canonical translator, saves encrypted per-shard artifacts, and verifies their complete union before packing. This addresses CI duration; it is not evidence of game compatibility. The upstream merge changed the shader chain to `dec5ee141a9f`, so older chain outputs cannot be used with the current host.
